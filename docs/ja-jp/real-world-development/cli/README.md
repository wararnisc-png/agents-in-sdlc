**[GitHub Copilot CLI][about-copilot-cli]** は、GitHub Copilot をターミナルで使えるエージェント型コーディング アシスタントです。コードベースの調査、コードの生成、コマンドの実行、外部ツールへの接続をコマンドラインから行えるため、グラフィカル エディターに切り替えずに作業を続けられます。

このワークショップでは、Tailspin Toys の一連の作業を通して学びます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、プロジェクトを確認します。
2. 星評価の変更を行い、ブラウザーで確認して、最初のプルリクエスト (PR) を手動でマージします。
3. フィルターの issue を起点に、Plan モードで方針を決め、Autopilot モードで実装し、Interactive モードでレビューします。
4. リポジトリの指示を更新し、フィルターの作業に適用します。
5. 既存の `quality-checks` スキルを調整し、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーでフィルターを確認します。
7. quality assurance (QA) カスタム エージェントを作成し、要件、テスト範囲、検証結果をレビューします。
8. フィルターの変更全体を確認し、Agent Merge を使って PR をマージします。
9. コンテキスト、モデル、共有、cloud agent への任意の委任に使えるスラッシュ コマンドを確認します。

ワークショップでは、星評価と、指示・スキル・QA プロファイル・テストを含むフィルターの 2 つの PR を作成します。どちらも更新済みの `main` から開始します。フィルターと品質チェックの作業では、同じ会話とブランチを使って各ツールの内容を積み上げます。

## 前提条件

このワークショップに参加する前に、次を準備してください。

- [ ] **Copilot Student、Pro、Pro+、Business、Enterprise** のいずれかの有効なプランがある GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンド ライン操作の基本的な知識

> [!TIP]
> 有料プランをお持ちでない場合、認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使用する agent、MCP、コードレビュー、Copilot CLI の機能が含まれています。

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用している場合は、管理者が Copilot CLI を有効にしていることを確認してください。
